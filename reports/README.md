# Reports

Machine-local validation, benchmark, and status outputs live under `latest/`.

## Layout

| Path | Purpose |
|------|---------|
| `latest/` | Current run outputs (JSON, Markdown, shell snippets). Regenerated by stage scripts. |
| `tmp/` | Scratch output during a run (gitignored). |
| `archive/` | Optional historical copies (gitignored). |

## Do not commit `latest/`

Contents of `reports/latest/` are host-specific (BIOS version, kernel, NPU
state, timestamps, local paths). They are produced when you run the toolkit,
for example:

```bash
./ai370-optimize.sh stage1
./ai370-optimize.sh stage1-validate
```

Scripts create `reports/latest/` as needed (`mkdir -p`). Clone the repo and run
the stages you care about to populate reports on each machine.
